QUESTION 4: Make a branch, create a known conflict, resolve it and merge it back into the main branch.

# Create and commit the initial README on main:
vi README.md
git add README.md
git commit -m "Add repository README"

# Create a branch and edit the README description in vi to:
# This repository contains completed exercises from the BPSM course lectures 3 and 4.
git switch -c improve-readme
vi README.md
git diff
git add README.md
git commit -m "Add more detail to README"

# Switch back to main and edit the same description to:
# This repository contains code and answers from the BPSM exercises.
git switch main
vi README.md
git add README.md
git commit -m " Update README description"

# This merge intentionally produced the required conflict in README.md:
git merge improve-readme
git status
cat README.md

# Select the working merge tool and resolve the conflict interactively:
git config --global merge.tool vimdiff
git mergetool
git st

# Remove the temporary files created during this recorded merge session:
rm README.md.orig README_BACKUP_*.md README_BASE_*.md README_LOCAL_*.md README_REMOTE_*.md
git commit
git lo

# Successful merge commit: 92e72e7, Merge branch 'improve-readme'.
